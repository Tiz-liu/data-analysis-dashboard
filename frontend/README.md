# BI智能数据分析面板 - 前端

## 技术栈

- **Vue 3.5.24** - 渐进式JavaScript框架
- **TypeScript 5.9.3** - JavaScript超集
- **Vite 7.2.4** - 下一代前端构建工具
- **Element Plus 2.5.x** - Vue 3 UI组件库
- **ECharts 5.5.x** - 图表库
- **Pinia 2.1.x** - Vue状态管理
- **Vue Router 4.2.x** - 路由管理
- **Axios 1.6.x** - HTTP客户端

## 开发命令

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览生产构建
```bash
npm run preview
```

- ✅ Vue 3 + TypeScript + Vite
